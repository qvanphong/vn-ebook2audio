Voice machines

The machines that make the speech: this server and any number of voice workers. In Convert you choose which of them share a book. The library, the files and this page always stay on this server. Texts per request sets how many sentences a machine gets in one request. VieNeu works on a batch together on a GPU (Turbo with CUDA); on a CPU it runs them one after another, so there a higher number only saves round trips.

Calibre-Web

Your Calibre-Web server, to browse and convert its books from the Calibre tab. It uses the OPDS catalogue, which must be switched on in Calibre-Web (Admin → Edit Basic Configuration → Feature Configuration → Enable OPDS). The password is kept on this server, in data/config/calibre.json (mode 600), and never sent back to this page.
How to start a worker
On each machine that will help (Python 3.12 and ffmpeg installed), in this project's folder:
pip install -r requirements-worker.txt
WORKER_NAME="Laptop" WORKER_TOKEN=choose-a-secret python -m app.worker
It listens on port 8780. Add it above with its address and token, press Test, then Save. Add as many as you like. A phone works only if the models can run there; anything that speaks the worker protocol described in the README can be used. A machine that has not downloaded or loaded the chosen model yet does that when a conversion starts, and the Jobs tab shows it doing so.
